# Recipe Search with Ingredients Filter (API Based)

## Project Title
Recipe Search with Ingredients Filter Using API

## Developed By
D. Nethra

## Introduction
This project is a web application that helps users search for recipes using ingredients. It uses an API to fetch recipe data and display recipe details such as ingredients, cooking instructions, and images.

## Features
- Search recipes by ingredient name
- API-based recipe fetching
- Responsive user interface
- Recipe image display
- Easy and fast recipe search
- User-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript
- React.js
- Recipe API

## Project Objective
The objective of this project is to help users find recipes easily based on available ingredients and improve the cooking experience.

## How It Works
1. User enters an ingredient name.
2. The application sends a request to the Recipe API.
3. The API returns matching recipes.
4. The recipes are displayed with images and details.

## Benefits
- Saves time in searching recipes
- Easy to use
- Provides recipe suggestions instantly
- Helps users utilize available ingredients
