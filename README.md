# Recipe Search with Ingredients Filter (API Based)

## Project Description
This project helps users search recipes and filter them using ingredients. The application fetches recipe data from an API and displays results in a simple interface.

## Features
- Search recipes by name
- Filter recipes by ingredients
- View recipe images
- Responsive design
- API integration

## Technologies Used
- HTML
- CSS
- JavaScript
- MealDB API

## How to Run
1. Download the project files.
2. Open `index.html` in a web browser.
3. Enter a recipe name.
4. Click Search to view recipes.
